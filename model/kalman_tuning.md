# Kalman 滤波器参数调优指南

## 模型概述

6 状态恒速模型：`[cx, cy, vx, vy, w, h]`

```
状态转移 (每帧 dt=1):
  cx' = cx + vx
  cy' = cy + vy
  vx' = vx
  vy' = vy
  w'  = w
  h'  = h

观测: [cx, cy, w, h]  (vx, vy 不可直接观测)
```

## 三个核心参数

| 参数 | 类默认值 | 实际初始值 | 矩阵 |
|------|---------|-----------|------|
| `process_noise` | 0.03 | **0.05** | `processNoiseCov` (Q) |
| `measurement_noise` | 0.1 | **0.15** | `measurementNoiseCov` (R) |
| `velocity_decay` | 0.85 | **0.80** | 丢失时速度倍率 |

---

## 1. process_noise (Q) — 模型不确定度

**含义**：运动模型和真实运动之间偏差的大小。

> Q 大 = "我不信恒速模型，目标可能随时变速" → 更信测量值
> Q 小 = "我信恒速模型，目标匀速运动" → 更信预测值

| 场景 | 建议值 | 效果 |
|------|--------|------|
| 目标匀速运动 | 0.01 ~ 0.03 | 轨迹平滑，滞后小 |
| 目标频繁变速 | 0.05 ~ 0.15 | 响应快，有轻微抖动 |
| 目标剧烈机动 | 0.15 ~ 0.5 | 跟得上，但噪声抑制弱 |

**运行时调节**：`w` 增大 (×1.3)，`s` 减小 (×0.7)

---

## 2. measurement_noise (R) — 观测不确定度

**含义**：检测结果有多不可靠。

> R 大 = "检测不准，噪声大" → 更信模型预测，平滑但滞后
> R 小 = "检测很准" → 更信检测值，响应快但保留噪声

| 场景 | 建议值 | 效果 |
|------|--------|------|
| 检测框稳定、精度高 | 0.03 ~ 0.08 | 快速跟踪 |
| 检测框有明显抖动 | 0.1 ~ 0.2 | 适量平滑 |
| 检测框跳动严重 | 0.2 ~ 0.5 | 强平滑，响应偏慢 |

**运行时调节**：`t` 增大 (×1.3，更平滑)，`y` 减小 (×0.7，更响应)

---

## 3. velocity_decay — 丢失预测衰减

目标丢失期间，每帧速度乘以该系数，实现预测位置逐渐"刹车"。

| 值 | 行为 | 适用场景 |
|----|------|---------|
| 0.95 ~ 1.0 | 丢失后持续匀速预测 | 高速运动、短暂遮挡 |
| 0.80 ~ 0.90 | 丢失后缓慢减速 | 中速运动、一般遮挡 |
| 0.60 ~ 0.75 | 丢失后快速停止 | 目标可能静止 |

---

## 卡尔曼增益的直观理解

```
输出 = 预测 + K × (测量 - 预测)

K = P_pred / (P_pred + R)

P_pred = P_post + Q  (预测步)
P_post = (1 - K) × P_pred  (更新步)
```

- Q 大 → P_pred 大 → K 接近 1 → 输出接近测量值
- R 大 → K 接近 0 → 输出接近预测值

**稳态下 K 由 Q/R 的比值决定**，不是绝对值。

## 调参流程

### 第一步：观察基准

启动程序，让目标保持**静止或匀速运动**，观察屏幕显示的 `vx/vy` 和检测框抖动情况。

### 第二步：调 R（去抖动）

```
目标不动，但检测框抖动 → 按 t 增大 R，直到抖动被抑制
目标不动，检测框也稳定 → 不用改 R
```

### 第三步：调 Q（测响应）

```
快速晃动目标，观察 Kalman 框是否跟得上
  跟得上 → 不改
  有明显的滞后 → 按 w 增大 Q
  跟得上但抖动太大 → 适当降 Q (按 s)，同时再增大 R
```

### 第四步：测丢失行为

```
故意遮挡目标 0.5~1 秒，看预测框的行为
  预测框飞走了 → 减小 velocity_decay（改代码）
  预测框停太快 → 增大 velocity_decay（改代码）
  丢失时间不够 → 增大 max_disappear_frames（改代码）
```

### 第五步：微调

重复二到四步，每次只改一个参数，直到满意。

## 常见问题

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 框明显滞后于目标 | Q 太小 | `w` 增大 process_noise |
| 静止目标框也在抖 | R 太小 | `t` 增大 measurement_noise |
| 快速运动跟不上 | Q 太小 或 R 太大 | `w` 增大 Q，`y` 减小 R |
| 丢失后框乱飞 | velocity_decay 太大 | 改代码减小到 0.7 |
| 短暂遮挡就重置 | max_disappear_frames 太小 | 改代码增大到 30~60 |

## PID 控制参数

### 参数表

| 参数 | 值 | 说明 |
|------|-----|------|
| `PID_FREQ` | 200 Hz | 控制频率，dt=0.005s |
| `PID_X_KP` | 1.7 | X轴比例增益 |
| `PID_X_KI` | 0.4 | X轴积分增益 |
| `PID_X_KD` | 0.10 | X轴微分增益 |
| `PID_Y_KP` | 1.4 | Y轴比例增益 |
| `PID_Y_KI` | 0.4 | Y轴积分增益 |
| `PID_Y_KD` | 0.10 | Y轴微分增益 |
| `PID_MAX/MIN` | ±3000 | 输出限幅 (RPM) |
| `PID_ERROR_CLAMP` | 120 | 误差钳位 (px)，限制转弯时 PID 输入 |

### 误差钳位说明

转弯时目标偏移可达数百像素，`PID_ERROR_CLAMP` 将误差限制在 ±120px 以内，
防止 PID 输出过大导致电机高速转动。配合降低后的 Kp，P项最大输出 ≈ 0.8×120 = 96 RPM。

| 按键 | 作用 |
|------|------|
| `w` / `s` | process_noise 增大/减小 |
| `t` / `y` | measurement_noise 增大/减小 |
| `u` | 重置 Kalman 状态 |
| `a` / `z` | PID X 轴 Kp 增大/减小 |
| `d` / `c` | PID X 轴 Ki 增大/减小 |
| `f` / `v` | PID X 轴 Kd 增大/减小 |
| `g` / `b` | PID Y 轴 Kp 增大/减小 |
| `h` / `n` | PID Y 轴 Ki 增大/减小 |
| `j` / `m` | PID Y 轴 Kd 增大/减小 |
| `o` / `l` | 误差钳位 ±10 |
| `r` | 清零 PID 积分 |
| `空格` | 暂停/继续 |
| `q` | 退出 |

## 当前初始值

```python
# Kalman
process_noise    = 0.05
measurement_noise = 0.15
velocity_decay    = 0.80
max_disappear_frames = 20   # ~0.67秒 @30fps

# PID
PID_X_KP = 0.8      PID_Y_KP = 0.7
PID_X_KI = 0.15     PID_Y_KI = 0.15
PID_X_KD = 0.10     PID_Y_KD = 0.10
PID_MAX  = 800      PID_MIN  = -800
PID_ERROR_CLAMP = 120
```

偏平滑的配置：
- Kalman 适合检测有一定噪声、目标中低速运动的场景
- PID 降低增益 + 误差钳位，避免转弯时电机高速转动
